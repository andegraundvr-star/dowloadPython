# Детектор хвостов (Tail Detection App)

Приложение для обнаружения хвостов на фотографиях котов с использованием YOLO.

##  Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/tail-detection.git
cd tail-detection


Установите зависимости:

pip install -r requirements.txt

Скачайте модель / запуск

python app.py
