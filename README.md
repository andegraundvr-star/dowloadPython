# 📊 Data Science & ML Projects Portfolio

Репозиторий с проектами по машинному обучению, анализу данных и визуализации.

## 📁 Структура проекта

dowloadPython/
├── notebooks/ # Jupyter ноутбуки с исследованиями
│ ├── 01_regression/ # Линейная и полиномиальная регрессия
│ ├── 02_classification/ # Классификация, KNN, деревья решений
│ ├── 03_clustering/ # Кластеризация, K-means, DBSCAN
│ └── 04_other/ # Другие эксперименты и практики
├── src/ # Python модули и скрипты
│ ├── utils/ # Вспомогательные функции
│ └── models/ # Реализации моделей ML
├── data/ # Примеры данных и датасеты
├── sql/ # SQL скрипты и запросы
├── docs/ # Документация и пояснения
└── assets/ # Изображения, графики, схемы

## 🛠 Технологический стек

- **Python 3.x** с основными библиотеками:
  - Pandas, NumPy (анализ данных)
  - Matplotlib, Seaborn (визуализация)
  - Scikit-learn, XGBoost (машинное обучение)
  - Jupyter (интерактивные ноутбуки)
- **SQL** (PostgreSQL, SQL Server)
- **Git & GitHub** (контроль версий)
